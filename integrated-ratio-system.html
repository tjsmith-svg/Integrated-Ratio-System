How to use

This app runs the spray shot-counter and monitors the A/B mix ratio at the same time.

Before you start

  • Use Chrome on Android. Keep the screen on and this page in front the whole time — the Bluetooth link and the timer both stop if you switch apps or the screen sleeps.
  • Put one scale under each vessel. Turn the cordless remotes off (a scale talks to only one thing at a time).

Connecting

  • Scales: connect them one at a time so each lands on the right side. Power on the A vessel's scale only, tap Connect Scale A, pick it; then do the same for Scale B. Order does not affect the ratio.
  • Pressure sensor (optional): tap Connect Pressure Sensor to use the PT-800 for timing.

What drives the timer

Pressure comes from the best source available, in this order: pressure sensor → average of both scales → manual entry. A live sensor reading is used first because it measures pressure directly; the scales infer it from vessel weight. The active source is shown under the Pressure field.

The ratio

Tap Start to set the baseline. From there the app tracks how much each vessel has dispensed and shows the live A:B ratio. It should stay near 1.00.

Warnings (red banner + beeping)

  • Ratio off: once about half a pound has been used on either side, if the two diverge by more than 10% the ratio is flagged.
  • Flow mismatch: if one vessel is clearly dispensing while the other is barely moving, it alarms — this points to a clogged gun, closed valve, or empty vessel. Stop before more off-ratio material is shot.
  • Scale/sensor stale: if a connected device stops sending data, the app warns and the timer falls back to the next available source.

If Bluetooth is unavailable

You can always type the pressure into the Pressure field and run the counter manually.
